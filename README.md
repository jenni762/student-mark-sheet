#.Student Mark Sheet
*About the Project
This is a beginner-friendly C++ project that manages student marks for three students across three subjects.
*Features
-Input student names and marks
-Calculate total and average marks
-Display a formatted student mark sheet
-Identify the student with the highest total score
*Concepts Practiced
-C++ arrays
-For loops and nested loops
-input and output
-Conditional statements
-iomanip
-cin.ignore() and getline()
*Language
-C++
